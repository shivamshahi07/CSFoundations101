# Git & GitHub - Knowledge Check

Test your knowledge of version control and Git commands! Answers are at the bottom.

### 1. Which command is used to initialize a new Git repository?
A) `git start`
B) `git init`
C) `git new`
D) `git create`

### 2. How do you stage all modified files for a commit?
A) `git add all`
B) `git stage *`
C) `git add .`
D) `git commit all`

### 3. Which command combines staging all tracked files and committing them with a message?
A) `git commit -a "message"`
B) `git commit -am "message"`
C) `git push -am "message"`
D) `git add commit "message"`

### 4. What is the correct branch naming convention for fixing a bug?
A) `bug-fix/heading`
B) `fix/heading-font`
C) `error/heading`
D) `patch/heading-font`

### 5. How do you switch to a new branch called `feat/login`?
A) `git checkout feat/login`
B) `git switch -c feat/login`
C) Both A and B (with `checkout -b` for creating)
D) `git branch feat/login`

### 6. What command downloads an entire repository from GitHub to your local machine?
A) `git copy`
B) `git clone <URL>`
C) `git download <URL>`
D) `git pull <URL>`

### 7. What does the "origin" refer to in `git push origin main`?
A) The local repository
B) The very first commit ever made
C) The default name of the remote repository on GitHub
D) The main branch

### 8. If you want to contribute to someone else's public repository, what is the FIRST step?
A) Clone their repository directly
B) Ask them for their password
C) Fork the repository on GitHub
D) Create a new branch

### 9. Which command shows you the current state of your working directory (what is staged/unstaged)?
A) `git log`
B) `git status`
C) `git show`
D) `git state`

### 10. When contributing to an open-source project, how do you submit your code for review?
A) Send an email with the code
B) Force push to their `main` branch
C) Create a Pull Request (PR) on GitHub
D) Comment the code on an issue

---

### Answers
1. B
2. C
3. B
4. B
5. C
6. B
7. C
8. C
9. B
10. C
