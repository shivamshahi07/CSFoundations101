# Terminal & Command Line - Knowledge Check

Test your terminal navigation and file manipulation skills! Answers are at the bottom.

### 1. Which command lists all files and folders in the current directory?
A) `list`
B) `ls`
C) `dir`
D) `show`

### 2. How do you change your current directory to a folder named `projects`?
A) `move projects`
B) `cd projects`
C) `go projects`
D) `enter projects`

### 3. What does the command `pwd` do?
A) Prints the current working directory path
B) Prompts you to enter your password
C) Pauses the terminal
D) Prints working data

### 4. How do you create a new empty file named `index.html`?
A) `create index.html`
B) `new index.html`
C) `touch index.html`
D) `make index.html`

### 5. Which command creates a new directory/folder named `assets`?
A) `mkdir assets`
B) `makedir assets`
C) `newdir assets`
D) `create folder assets`

### 6. How do you go back one directory level (to the parent folder)?
A) `cd back`
B) `cd ..`
C) `cd /`
D) `cd -`

### 7. What is the command to remove (delete) a file named `old_file.txt`?
A) `del old_file.txt`
B) `remove old_file.txt`
C) `rm old_file.txt`
D) `delete old_file.txt`

### 8. How do you completely clear the terminal screen?
A) `clean`
B) `clear`
C) `wipe`
D) `refresh`

### 9. Which command outputs the contents of a file (e.g., `logs.txt`) directly into the terminal?
A) `cat logs.txt`
B) `read logs.txt`
C) `show logs.txt`
D) `print logs.txt`

### 10. What symbol is often used to represent the "home" directory?
A) `/`
B) `.`
C) `~`
D) `*`

---

### Answers
1. B
2. B
3. A
4. C
5. A
6. B
7. C
8. B
9. A
10. C
