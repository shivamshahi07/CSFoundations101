# Web Development - Knowledge Check

Test your knowledge of basic web development concepts! Answers are at the bottom.

### 1. What does HTML stand for?
A) Hyper Text Markup Language
B) Home Tool Markup Language
C) Hyperlinks and Text Markup Language
D) High Tech Modern Language

### 2. Which technology is primarily responsible for the styling and layout of a webpage?
A) HTML
B) CSS
C) JavaScript
D) SQL

### 3. What does CSS stand for?
A) Computer Style Sheets
B) Creative Style Sheets
C) Cascading Style Sheets
D) Colorful Style Sheets

### 4. Which of the following is used to add interactivity and logic to a webpage?
A) HTML
B) CSS
C) JavaScript
D) Markdown

### 5. In a typical web application, what does the "Frontend" refer to?
A) The server where the database lives
B) The part of the application that users see and interact with in their browser
C) The underlying operating system
D) The API routing

### 6. What does a "Responsive" web design mean?
A) The website loads very fast
B) The website looks good and adapts to all screen sizes (desktop, tablet, mobile)
C) The website responds to voice commands
D) The website has a lot of animations

### 7. What is React.js / Next.js?
A) A database management system
B) A popular JavaScript library/framework for building user interfaces
C) A type of CSS processor
D) A web hosting platform

### 8. Which HTML tag is used for the largest, most important heading?
A) `<heading>`
B) `<h6>`
C) `<h1>`
D) `<head>`

### 9. What is a "DOM" in web development?
A) Data Object Model
B) Document Object Model
C) Display Oriented Module
D) Dynamic Output Method

### 10. What does an API do in web development?
A) It styles the webpage
B) It allows different software systems to communicate with each other (e.g., fetching data from a server)
C) It stores data permanently in the browser
D) It creates the HTML structure

---

### Answers
1. A
2. B
3. C
4. C
5. B
6. B
7. B
8. C
9. B
10. B
